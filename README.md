## [ComfyUI Anima Flow Corrective Sampler](https://github.com/KeithZ117/Comfyui-anima-sampler) wrapper for SwarmUI.

This extension will replace `SwarmKSampler` with `AnimaFlowCorrectiveSampler`.

Installation:
1. `cd {your SwarmUI directory}/src/Extensions`
2. `git clone https://github.com/khanghy1000/SwarmUIAnimaFlowSampler`
